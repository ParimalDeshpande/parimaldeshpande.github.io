# Managing Tasks and Project Workflows

*An independently created sample for a fictional software product.*

## Overview

Learn how to create, assign, and track tasks in FlowPilot.

## Create a task

1. Open a project.
2. Select **Add task**.
3. Enter a task title.
4. Assign an owner if needed.
5. Save the task.

Verify that the task appears in the project task list.
