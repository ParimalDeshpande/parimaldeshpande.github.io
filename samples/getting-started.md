# Getting Started with FlowPilot

*An independently created sample for a fictional software product.*

## Overview

This guide explains how to create your first project and add a task.

## Prerequisites

- Access to a FlowPilot account.

## Create a project

1. Sign in to FlowPilot.
2. Open **Projects**.
3. Select **Create project**.
4. Enter a project name and save.

Your project is ready for you to add tasks.
