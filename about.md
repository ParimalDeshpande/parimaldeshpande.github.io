# About me

I'm a Principal Technical Writer with 15+ years of experience creating documentation for enterprise software, SaaS products, mobile applications, APIs, and complex technical workflows.

I focus on making software easier to understand and use. My work includes end-user and administrator documentation, conceptual and task-based content, API documentation, contextual help, microcopy, What's New content, troubleshooting information, and instructional videos.

## What I do

My work spans the documentation lifecycle, from understanding product requirements and complex technical behavior to designing information structures, creating content, reviewing technical accuracy, and supporting publication and localization.

At PTC, I work extensively on Windchill and Windchill+ documentation. My experience includes:

- Creating administrator and user documentation for SaaS and on-premises products
- Designing information architecture and content structures for help centers
- Documenting complex product features, workflows, integrations, and configuration
- Creating developer- and integration-focused documentation, including REST API content
- Writing What's New content, feature documentation, and integration use cases
- Creating onboarding and feature-specific instructional videos
- Performing documentation impact analysis and technical reviews
- Maintaining structured DITA content and resolving validation, build, and link issues
- Working with localization teams to support multilingual documentation
- Using analytics and customer feedback to identify opportunities for content improvement

## Working across teams

Technical documentation is rarely created in isolation.

I work closely with product managers, engineers, QA teams, UX professionals, and other stakeholders to understand how features are designed and how users interact with them. I use that understanding to turn technical implementation details into documentation organized around what users need to know and do.

I have also mentored writers and interns on product fundamentals, documentation processes, installation, and translation workflows.

## Documentation and AI

I'm particularly interested in how AI can improve technical-writing and software-development workflows without compromising technical accuracy or human review.

My work in this area has included experimenting with AI-assisted authoring, API-description generation, Git-based workflows, Visual Studio Code, GitHub Copilot, and automation for creating first drafts of technical content.

I'm also exploring how agents, reusable skills, repository context, and AI-assisted review can support activities across the software development lifecycle, including requirements analysis, development, testing, documentation, and maintenance.

You can see an example of this approach in **Integrating AI Agents into the Software Development Lifecycle** under Writing samples.
